# AEOS AI-CAD｜RUGGED-H6000 高保真逆向建模项目

本仓库用于归档和持续推进 RUGGED-H6000 工作灯的多视图逆向建模、开源工具评估、STEP/STP 交付与保真度验证。

## 当前归档版本

- 方案版本：V1.0
- 归档日期：2026-11-13
- 项目阶段：开源工具路线评估与第二轮 A/B 实测准备
- 目标交付：可编辑 STEP/STP 零件与总装、装配结构、关键尺寸、工程验证报告和多视图保真度报告。

## 项目原则

1. 以用户提供的正面、背面、侧面、等轴测及工程图作为统一基准。
2. 先建立尺寸/轮廓基线，再进行主壳、灯杯、侧灯、铰链、提手、电池包和底座的参数化建模。
3. 图像生成结果只能作为参考，不得替代可编辑 CAD 几何。
4. 采用多视图、局部 ROI、轮廓距离、SSIM/IoU 和 STEP 几何有效性进行量化验收。
5. 每轮测试保留环境、依赖版本、执行日志、源文件、STEP、渲染图和评估结果。

## 目录规划

- `docs/`：项目方案、设计规范、执行与验收文档
- `tests/ab_round_2/`：第二轮开源工具 A/B 测试脚本、配置、报告
- `references/`：经授权纳入项目的参考图与基准文件
- `deliverables/step/`：通过验收的 STEP/STP 零件和总装
- `deliverables/reports/`：几何验证、尺寸核验和多视图保真报告
- `archive/`：版本化存档包
