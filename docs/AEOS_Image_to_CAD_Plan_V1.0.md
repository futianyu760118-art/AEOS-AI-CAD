# AEOS 图片转 STP 与零件图实施方案

2026 年 11 月 14 日 · 宁波恒剑光电研发试点 · V1.0

## 1 决策与可行性

建议在 M04 研发自治中心落地“上传图片 → 自动审阅包 → 工程签发”。首期覆盖有参数化模板的灯具，交图即建任务。首分钟返回识别、缺图、缺尺寸和预计交付时间。符合模板且资料齐全的任务，目标 15 分钟内自动交付首包。正式生产图依据实测尺寸、工艺和工程签发发放。

| 验证项 | 结果 | 适用范围 |
|---|---|---|
| H6000 整机 STEP | 正面拟合版重导入有效，172 个实体 | 有现成参数化源码的 CPU 重建。172 是 CAD 实体数，BOM 料号数需另定 |
| 正面铰链拟合 | 原图可见间隙中位数 35／35 px，修订版 35／37 px | 固定投影的局部视觉证据。整机包络约 482.4 × 195 × 364 mm，实物尺寸待确认 |
| 三件零件 STP 与出图 | 铰链轴套、护角、灯杯均从同一参数化模型拆出。STP、PDF、DXF、SVG 已生成 | 单件可自动生成审阅图。标注来自候选 CAD。公差说明已移除 |
| 零件阶段耗时 | 模型重建加三件拆出约 5.2 秒，单张三格式出图分别约 8.1、6.7、7.7 秒，串行合计约 28 秒 | 当前 Linux CPU、依赖已装、固定源码。此数字仅覆盖 CAD 与出图工序 |
| 从未见图片自动生成 | 待产品试点验证。H6000 的识别、造型和多轮拟合由视觉智能体参与完成 | 首批按模板命中率与可放行率计量 |
| Agentic CAD 多视图推理 | 已完成安装与输入预检，缺模型服务和 CUDA 的正式重建仍待验证 | 可作为实验路线。首期上线用现有 CPU 链路 |

## 2 输入要求与交付等级

| 输入 | 即时响应与自动输出 | 工程复核 |
|---|---|---|
| 一张图、无尺寸 | 识别类别与可见零件，提示补拍与比例尺。模板匹配成功可输出预览与参考模型 | 尺寸单位或比例未知时，STEP 标明尺度假设。看不到的结构列为未知 |
| 正、侧、背和斜视图，加至少一个可靠基准尺寸 | 校准各视图、匹配模板，自动生成整机 STP、零件 STP、图纸草稿和差异报告 | 对各视图姿态冲突做提示。照片中无法测到的孔深、壁厚、装配间隙仍待测 |
| 多视图、关键实测尺寸、装配要求与工艺信息 | 自动生成带已知标注的候选图、BOM 草稿及变更记录 | 工程师确认材料、工艺、尺寸链、基准、公差、干涉和配合，签发受控生产版 |

拍摄任务给出指引。拍正、背、左右侧、顶和两张斜视图。保持相同产品构型，标明折叠或展开状态。标尺与目标特征尽量在同一平面。上传实测总长宽高、主要孔径及孔距、接口和关键壁厚。每个尺寸记录来源、单位、视图、测量人及置信状态。证据分为实测、已有图纸、图像推定和未知。

## 3 操作流程与系统设计

1. 研发人员在 M04 选择产品和版本，拖入图片、已有 CAD 或测量表。后台生成任务 ID、输入哈希、资料版本与缺项清单。首页显示预计时间和当前状态。
2. 视觉模块输出产品类别、零件清单、基准点、轮廓、尺度和未确定特征，写入结构化参数。优先查同系列模板。两视图的姿态或比例冲突超出项目阈值时，进入补图或人工对齐队列。
3. 规则将参数映射到主壳、灯杯、灯板、护角、铰链、支架和电池包等模块。模板未命中则产生建模待办，视觉智能体在隔离环境生成候选源码，由工程师确认建模意图。每个总成保留零件坐标、对称关系和装配位姿。
4. Linux CAD 工作进程使用锁定的 img2cad、build123d、OpenCascade 版本构建、拆件、生成投影视图并出图。初期用脚本与队列，后续把图框、尺寸样式、剖切模板和签审字段纳入受控配置。以零件料号与版本出图，标准件、LED 阵列实例和镜像件按规则归并。
5. 系统复读 STP，校验实体、单位、装配坐标、零件数量、BOM 映射、图纸格式及尺寸一致性。独立对照真实图像的轮廓、关键点和零件间隙。CAD 有效性和图像误差分别记录。同源轮廓对照只用来检查轮廓输入和投影。
6. 通过自动检查即发布审阅包。工程师在同屏查看原图、CAD 和差异，签发生产版时确认所有关键尺寸及公差来源。M04 管理料号和工程版本，EDP 登记输入与证据。修改发起新版本，复用已有模板及成功步骤。相同输入、参数和工具版本命中缓存。失败可重试，单件失败应明确标出并允许续跑。

建议任务状态为已接收、待补资料、生成中、待工程复核、已签发或失败。失败记录原因及重试次数。以任务 ID 和输入指纹防止重复提交，以料号加版本防止同名覆盖。预览包链接与发布版本分开，附件带清单、校验值和权限。

## 4 交付物与出图口径

| 文件 | 内容 |
|---|---|
| 装配 STP | 可打开的命名实体、总成坐标和实例清单。输出 STEP 文件，可使用 .stp 扩展名 |
| 零件 STP | 一料号一份 B-rep。左右不同件单独输出，同料号重复件记录数量 |
| 零件 PDF、DXF | 三视图、必要剖面、总体尺寸、关键孔与定位尺寸。审核后加入基准、材料、公差、表面要求与签审栏 |
| 装配 PDF、BOM CSV | 装配视图、位置和序号、料号与数量。需要时增加爆炸图和装配顺序 |
| 可编辑源文件与参数 JSON | 参数化源码、尺寸来源、模板版本、相机对齐假设 |
| GLB 与验证报告 | 网页预览、原图与渲染对照、差异、缺项、STP 校验和发布级别 |

审阅图统一标注“仅供审阅”。照片推定值不自动绑定加工公差。生产版由工程师核定关键尺寸、公差与验收方法，尤其是铰链孔轴配合、壳体壁厚、灯杯光学曲面和支架装配间隙。自动识别的孔类型、螺纹和沉孔须按工艺复核。

## 5 时效与操作效率

下列为试点目标与估算。起点为资料上传完毕，终点按审阅包和生产版分别记录。机时、等待和人员实际工时单独采集。

| 产品任务 | 首包墙钟时间目标 | 人工总投入估算 | 适用条件 |
|---|---:|---:|---|
| 已有模板的规格变型 | 5–15 分钟 | 15–35 分钟 | 参数范围内、关键数据齐全、一次复核 |
| 同族新外观 | 30–120 分钟 | 1–3 小时 | 有稳定骨架、可复用零件，需调整曲面和部件 |
| 全新复杂总成 | 0.5–2 个工作日 | 4–12 小时 | 补量测和建模板。深腔、光学及机构件单独评估 |

产能示例采用工程师每天 6 小时有效工时、模板任务平均人工 25 分钟，理论约 14 单/人日。按 70% 排产，约 10 单/人日。该数字按审阅工作量估算，需实测并纳入返工。若传统模板出图基线为 90 分钟/单，新流程稳定在 25 分钟/单，理论减少约 72% 人工操作时间。恒剑现有基线尚未采样。

建议上线看板记录首包 P50/P90、人工分钟、首次通过率、补拍率、平均返工次数、零件图覆盖率、可签发率、每单成本。模板任务试点目标为首包 P90 ≤15 分钟、人工中位 ≤25 分钟、首次复核通过 ≥80%、自动交付的 STP/PDF/DXF 可打开率 100%。生产图关键尺寸的批准与可追溯率要求 100%。

## 6 成本预算与回收测算

以人民币计。内部综合工时单价暂按 ¥120/小时，实际应使用本公司财务核算口径。硬件与部署费用为估算，未采购。

| 成本项 | 预算或公式 |
|---|---|
| MVP 开发与样本验收 | 16–22 人日 × 8 小时 × ¥120 ≈ ¥15,360–21,120 |
| 现有工作站 | 复用时增量硬件 ¥0，另计电力、占用和运维。若采购，暂留 ¥5,000–10,000 询价额度 |
| 常规模板单人工 | 15–35 分钟 × ¥120/小时 = ¥30–70 |
| 同族新外观人工 | 1–3 小时 = ¥120–360 |
| 全新复杂总成人工 | 4–12 小时 = ¥480–1,440 |
| 本地计算 | 实际功率 kW × 占用小时 × 电价，加折旧与占用。0.15 kW × 0.25 小时 × ¥1/kWh ≈ ¥0.04/单，仅电费 |
| 可选视觉模型 | GPT-5.6 Sol 示例单价每百万输入 US$4、输出 US$20。若输入 30k、输出 10k，约 US$0.32/次。图片计入输入用量，重试、模型切换按实计 |
| 维护 | 规划每月 4–8 小时，约 ¥480–960。新增产品族建模板、量测和图框调整单独计入 |

CPU 端 CAD 构建和出图无需模型 API。识别及自动编写新产品参数时，可按授权选择模型服务。云 GPU 只用于另行验证的多视图推理，按实例小时、存储、模型调用和重试实报，费用未计入 MVP。发布前按锁定版本检查开源依赖和对外分发条款。API 价格以部署时官方报价为准。

若每月有 40 个模板单，按人工节省 65 分钟/单，可节省约 43 小时/月，折合约 ¥5,200/月。扣除上表维护后，约 ¥4,240–4,720/月，既有硬件下实施投入简单回收期约 3.3–5.0 个月。此情景假设订单量、人工基线及模板覆盖率成立，未计新增硬件、API、返工和上线爬坡。

## 7 实施分工与验收

| 日程 | 执行与验收 |
|---|---|
| 第 1–3 工作日 | 研发工程师冻结 H6000 可见关键尺寸、零件编号、图框和签审要求。技术负责人确认模板范围及生产图释放权限 |
| 第 4–8 工作日 | 开发人员接通上传、参数结构、任务队列、CAD 构建和拆件出图。用现有 H6000 验证整机、单件 STP 与 PDF/DXF 下载 |
| 第 9–12 工作日 | 测试人员执行不少于 10 个模板／同族任务，另加入至少 3 个缺图、缺尺寸或姿态冲突任务。保留传统手工基线、重跑日志、失败样本和成本账 |
| 第 13–15 工作日 | 对照 P90 时效、图纸覆盖、关键尺寸证据和实际人工投入。达标后开放模板产品试用，工程签发继续受控 |

预计 3 周完成首轮 MVP，16–22 人日为多人分摊。正式扩展产品族以试点数据决定。最低验收包括可打开的整机和零件 STP、对应 PDF/DXF、清单可追溯、关键尺寸能定位到来源，以及错误输入进入正确的补资料或人工建模流程。
